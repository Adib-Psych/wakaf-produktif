# Backup/recovery kit — credential independent, not commissioned

Existing selected destination remains private Drive Backup Sistem Wakaf. ADIB primary, PANJI backup; Adib alone approves access. No new ACL, upload, production schedule or capture is performed by this kit. Manual USB/key custody is not a prerequisite.

Run from repository root:

    python3 -B -m unittest discover -s recovery/backup -p 'test_*.py'
    python3 -B recovery/backup/operations.py --fixture /absolute/path/synthetic-fixture.json

backup_runner.py + business_guard.py retain the reviewed exact-project/database, explicit metric schema, shrinkage quarantine and last-good preservation mechanism. Its network mode is NOT commissioned; do not pass a production config. No auto-bootstrap baseline: an accepted archive is not a healthy baseline. Tests seed synthetic baselines only. Pure decode_value is extracted verbatim; legacy endpoint/configuration and main runner are not bundled.

operations.py validates a new synthetic fixture and produces a nondestructive retention proposal/alarm. It never deletes anything. A manifest pass cannot turn an offhost/recovery HOLD into READY. Suggested decision, not active policy: preserve every accepted archive and incident exception indefinitely pending their existing obligations; propose retaining the latest 30 routine successful captures before a separately approved deletion mechanism. No existing archive is reopened for acceptance.

system_kit.py builds deterministic JSON only from an explicit tracked regular UTF-8 code allowlist, then restores into a new empty server directory. It includes no database, browser queue, credentials or deployment configuration outside the allowlist. Pattern scanning is not a secret audit. Database restore, remote downloaded-copy proof, IAM/Console configuration, media and managed-account recovery remain separate gates. The kit is provider-free and can run without AI or Luna/Mac; no scheduler is installed.

Reuse existing isolated actual-data drill evidence by hash only. Do not rerun its one-shot marker. New synthetic emulator drill evidence is separate and does not certify financial correctness, actual offhost recovery or Drive OAuth durability.
